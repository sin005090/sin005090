사용자의 성향과 날씨, 위치를 바탕으로 운동과 주변 체육시설, 스포츠 행사를 추천하는 서비스 (팀 프로젝트)

`Java 17` `Spring Boot` `MyBatis` `MariaDB` `JSP`

- **운동 완료 · 운동 리포트** 백엔드 구현
- **OpenWeather API** 연동 날씨 기능
